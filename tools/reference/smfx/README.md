# SporeModder FX reference files

Unmodified copies from [SporeModder FX](https://github.com/Spore-Community/SporeModder-FX) by Eric Mor (emd4600) and the Spore modding community, licensed under the GNU GPL v3 (see `LICENSE.md`).

- `SporeUIDesignerProjectCommon.xml` / `SporeUIDesignerProjectCustom.xml` are read by `tools/spore/spui.py` to name UI classes and properties.
- The `.java` files were used as documentation of the `.spui` binary format.
